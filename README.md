# Calculator

A clean, responsive calculator web app built with vanilla HTML, CSS, and JavaScript.

## Features

- Standard arithmetic: addition, subtraction, multiplication, division
- Decimal, percentage, and positive/negative toggle support
- Chained operations with running expression display
- Keyboard support (numbers, operators, Enter, Backspace, Escape)
- Error handling for divide-by-zero and invalid input
- Dark theme with smooth button animations
- Fully responsive — works on desktop and mobile

## Deployment

This project is deployed via **GitHub Pages** using a GitHub Actions workflow.

To deploy your own copy:

1. Create a new GitHub repository (do **not** initialise with a README)
2. Add the remote: `git remote add origin https://github.com/YOUR_USERNAME/YOUR_REPO.git`
3. Push: `git push -u origin main`
4. In the repo settings, go to **Pages** and set the source to **GitHub Actions**
5. Visit: `https://YOUR_USERNAME.github.io/YOUR_REPO/`
